# Used-car brand logo sources

The runtime consumes the local `brand-*.webp` files in this directory. These files are visual identifiers only; every mark remains the trademark of its respective owner.

## Dataset-derived marks

The following marks were copied from the optimized PNG set in [`filippofilip95/car-logos-dataset`](https://github.com/filippofilip95/car-logos-dataset) (snapshot downloaded 2026-08-17) and converted locally to 320 × 160 WebP with transparency preserved. That repository records its upstream image URL per brand in `logos/data.json` and notes that trademark rights remain with the brand owners.
